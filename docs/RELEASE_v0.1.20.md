# Solasta Coop Mod v0.1.20

**Windows x64**, experimental co-op quality-of-life mod for Solasta: Crown of the Magister.

## Changes

- Renamed **Solasta Coop View** to **Solasta Coop Mod** in the F8 overlay, diagnostics, logs and documentation.
- Simplified F8 settings with shorter labels and concise descriptions.
- Added on/off toggles for **combat animation speed**, **extended camera zoom** and **host waypoint sharing**.
- Switched the network transport selection to a **TCP toggle**. Connection retry remains a separate toggle.
- Kept the existing auto-accept controls for fast-travel votes and post-loading confirmation.
- Updated the managed payload and log folder names for the new project name.

## Installation

1. Close Solasta on both computers.
2. Download **winhttp.dll** from the assets below.
3. Copy the DLL beside **Solasta.exe**, inside the game installation directory.
4. Use the **same mod version** on all co-op clients.
5. Press **F8** to open the settings.

## Important

The mod remains unofficial and multiplayer features have not been exhaustively tested. Back up your save. Do not replace the system Windows winhttp.dll. All compiled gameplay patches are embedded in the single release DLL; no proprietary game assemblies are distributed.
